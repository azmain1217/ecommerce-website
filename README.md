# Circuit Supply

A responsive electronics storefront prototype built with React and Vite.

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build`.

## Storefront features

- Product search, category filters, and price/rating sorting
- Saved products, product detail quick view, and side-by-side comparison
- Shopping bag with quantity controls, shipping threshold, subtotal, and total
- Responsive catalog and mobile category navigation
- `Command+K` or `Control+K` focuses search; `Escape` closes open overlays

Product and order state is local to the browser session. Checkout is a demo action and does not process payment or create a real order. Product photography and web fonts load from Unsplash and Google Fonts.
